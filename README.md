# ANTHONY | Ropa masculina

Sitio web de ropa masculina moderna, cómoda y con estilo propio.

## 👕 Sobre el proyecto

ANTHONY es una página web creada para presentar una colección de ropa masculina, mostrar prendas y facilitar el contacto con los clientes.

## 🛍️ Colección

El sitio incluye una colección de prendas masculinas con fotografías reales de los productos.

## 📱 Diseño

- Diseño adaptable para celulares
- Navegación sencilla
- Sección de colección
- Sección sobre la marca
- Sección de contacto
- Fotografías de las prendas

## 🌐 Publicación

El sitio está publicado mediante **GitHub Pages**.

## 📁 Archivos principales

- `index.html` — Página principal
- Fotografías `.jpg` — Imágenes de la colección
- `README.md` — Información del proyecto
